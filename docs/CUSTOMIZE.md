# 让她长成你自己的样子

开源版不带任何固定的名字、头像、表情包。**这些都由你自己定，而且不存在"一键导入别人的人格包"这种捷径。**

## 名字

```json
// bot/config.json
{ "instanceName": "你给她起的名字" }
```

没填时从 `life/SELF.md` 的「我叫 X」/「我是 X」读；都没有就显示「她」。

面板标题、通知标题、客户端显示的默认名字都用它。

## 头像

头像在 **VoceChat 里设置**（她的账号 → 设置 → 头像），客户端显示的是 VoceChat 返回的资料。

原因：头像是 IM 账号的属性，不是人格文件。放在 IM 里，换客户端也一致。

## 表情包：一张一张加

**没有"表情包压缩包导入"这个功能，是有意的。** 每张图要有人写清楚它是什么情绪、什么场合，否则她只会乱用。

```bash
bash deploy/meme-add.sh ~/图片/害羞.jpg
```

会问你四件事：

```
分类（可新写，如 shy）
标签（逗号分隔，她按标签找图）
描述（一句话：这张图什么情绪/场合）
情绪名（她 meme 字段里的值）
```

然后写进 `life/shelf/memes/index.jsonl`，图片复制到 `life/shelf/memes/<分类>/`。

**建议一次加 5–20 张、覆盖常见情绪就够用**（开心、害羞、得意、累、无语、生气、难过）。加太多她反而挑不出来。

## 她现在的声音（提示词语气）

在 `bot/persona.md` 和 `src/core/mind.mjs` 的 `RULES` 里。
**这两处属于"她是谁"，改动要走申请流程**（见 README 的边界表）。

## 不建议做的事

- 把别人的 `SELF.md` / `taste.md` 打包分享或导入——那等于复制别人的人。
- 一次塞几百张表情包、不写标签——她会按文件名瞎猜。
- 直接改她的 `memory.md` 让她"记得"什么——那是替她编记忆。
