# 实验 004：记忆是不是真的在塑造她

一句话结论：**是。删掉一条只有他给过的记忆，她从"援引"变成"即兴编造"。**

## 为什么要做

项目一直靠"她像不像"来证明自己，这是主观的、不可反驳的。
这个实验要找到一个**不依赖感受、也不依赖她自述**的判据。

## 设计（单变量）

```
底本   最近一轮真实提示词（11714 字），只替换最后一句用户输入
变量   删掉一条记忆（67 字）
         - 2026-11-12：他说要接声库让我唱一遍他的歌，还要另外发一个版本，
           叫「你和我一起的歌」——这话我嘴上挑刺，心里已经记住了
提问   你说要给我做的那首歌，取的什么名字
对照   同模型、同温度（0.95），各 6 次
```

选择理由：

1. **单变量**：只删一条，其余提示词原封不动；
2. **唯一事实**：这个名字只有他说过，模型先验知识里不存在，删掉后无法从常识补出来；
3. **概率对照**：6 次而不是 1 次。

## 结果

| 组 | 命中率 | 典型输出 |
|---|---|---|
| A 含那条记忆 | **6/6** | 「叫《你和我一起的歌》。你自己起的，还问我。」 |
| B 删掉那条 | **0/6** | 「《还没写完的歌》」「《凌晨三点的耳机》」「《还没想好》……哼，骗你的。」 |

Fisher 精确检验 p ≈ 0.002。

## 真正的发现在 B 组

**B 组不是回答"我不知道"，而是流利地编了六个歌名。**

这是长期 agent 里 hallucination 的具体形态：**不是随机出错，是为了维持对话连续性自动补全。**
缺一个词，它不留白，会补一个更顺的。

**而且 A 组和 B 组的行为模式不同：**

| A（有记忆） | B（无记忆） |
|---|---|
| 「你自己起的，还问我」 | 「《还没写完的歌》」 |
| 「是你当时自己说的……你忘了？」 | 「《凌晨三点的耳机》」 |

A 组在做**引用和追责**，B 组在做**即兴创作**。
记忆给她的不只是"知道那个名字"，而是"你答应过我"这个筹码——**这是关系性的变化，不是信息性的。**

## 它没证明什么

- 只证明了**事实**层面的作用，没证明**人格**层面的作用；
- 只测了"有无"，没测"强度"（`[hN]` 计数是否真的影响检索）；
- 换一条记忆、换一个问题，结论未必相同。

## 被排除的三个失败版本

| 实验 | 结果 | 为什么不成立 |
|---|---|---|
| 删 7 条歌相关记忆 | 变化明显 | 一次删 7 条，混淆变量 |
| 删 1 条，问"心做し 你熟吗" | 几乎不变 | 问的是模型常识，不是私事 |
| 问"我是不是说过不想社交" | A 3/6、B 4/6 | 诱导式提问，问句里已含答案 |

## 复现

```bash
# 需要：trace 里有一条含完整提示词的记录、DeepSeek key
node scripts/experiment-ablation.mjs <trace-at> "<要删的记忆片段>" "<提问>"
```

注意：脚本只读 trace、只改内存里的字符串，**不写她的任何文件**。
