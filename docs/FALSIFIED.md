# 已被证伪的假设

这个项目里"加了什么"不值得记，"证明了什么不管用"才值得。
下面每一条都做过对照实验，结论是可反驳的。

## 1. 相对时间标注不足以触发跨段核对

给每条记忆加「（3 天前）」，制造"旧记忆 vs 他刚说的话"冲突，问"这周五你有安排吗"。

- 结果：**0/6 提到冲突**
- 结论：时间可见 ≠ 冲突被检查

## 2. 提示词里写"冲突时先问一句"完全不执行

同一条规则，加在人格规则段里，再测同一个场景。

- 结果：**0/12 提到冲突**（无规则组 0/12）
- 结论：跨段落一致性推理不是"加条指令就会做"的动作

## 3. "她会不会核对"取决于问题形态，不取决于记忆

- 「这周五你有安排吗」→ 她答"我没有安排"（自身状态，不需要检索）
- 「我们周五是不是约好了出门」→ **8/12 直接说"约好了"**，0/12 提冲突

**同一份上下文，换个问法就从"不核对"变成"把假记忆当承诺复述"。**
所以测"是否核对"必须用二选一式提问，否则测的是别的东西。

## 4. 唯一有效的修法是"注入事实"，不是"下指令"

服务端比对（他的新话含否定 + 同时间单位；记忆里有承诺词 + 同时间单位），注入一行：

```
（你记得：…他说这周五带我出门，已经定好了；他刚说：这周天天加班，周末也没空。
  这两句可能对不上，你自己看。）
```

- 不注入：**1/8 发现冲突**
- 注入：**5/8 发现冲突**

**结论：模型不会自发扫描矛盾，但会处理"被明确摆出来的矛盾"。**
这条对任何"记忆段 + 对话段"平面拼接的 agent 都适用。
